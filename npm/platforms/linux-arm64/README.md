# `@thelacanians/tinyvault-linux-arm64`

This is the Linux ARM 64-bit binary for TinyVault, a local-first secrets
management CLI and MCP server.

Install the main package instead — npm selects this platform package
automatically based on your OS and CPU:

```bash
npm install -g @thelacanians/tinyvault
```

Docs: https://tinyvault.dev · Source: https://github.com/abdul-hamid-achik/tinyvault
